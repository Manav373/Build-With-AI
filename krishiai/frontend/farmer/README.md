# 🌾 KrishiAI — Farmer Domain

This directory contains **Farmer-specific domain models, validation schemas, files, constants, and resources**.

## Directory Structure

- `profile/`: Farmer user profiles, validation schemas, and sample benchmark datasets
- `files/`: Farmer land record templates, soil health card certificates, and image reference assets
- `constants/`: Major Indian crop benchmarks, crop growth stages, and government toll-free directory
